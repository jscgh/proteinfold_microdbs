# ProteinFold microdatabases

Small database subsets for testing protein-folding workflows without downloading the full production databases. The payload is under [`microdbs/`](microdbs/) and includes reduced sequence, template, RNA, and ColabFold/MMseqs databases.

Model weights and parameter files are intentionally excluded: they are generally too large for GitHub, cannot be meaningfully reduced, and may have separate licence terms. Supply them separately when running a model.

## Contents

- Sequence/MSA subsets: BFD, MGnify, UniProt, UniRef30, UniRef90, and small BFD.
- Template subsets: PDB70, PDB100, PDB seqres, and the matching mmCIF files.
- RNA subsets: Rfam, RNAcentral, and NT-RNA.
- ColabFold subsets: UniRef30 and environmental MMseqs databases without large precomputed indices.

The data retain their upstream database terms; verify those terms before redistribution or reuse.

## Rebuild

The builder selects hits observed in archived workflow outputs and refreshes the supported FASTA, template, and ColabFold/MMseqs subsets in the checked-out `microdbs/` tree. Static RNA, BFD, and HH-suite UniRef30 fixtures are not regenerated by this script. It requires Bash, HH-suite/FFindex, MMseqs2, zstd, the full ProteinFold databases, archived work outputs, and a sample CSV.

```bash
scripts/truncate_micron_from_sample_hits.sh \
  /path/to/work \
  /path/to/full/proteinfold_dbs \
  ./microdbs \
  /path/to/samples.csv \
  4 12 ./rebuild.log 0 12
```

The positional values after the CSV are: hits per sample unit, maximum total hits, log path, file-age window in minutes (`0` means all archived files), and ColabFold hit count. Generated logs and `microdbs/params/` are ignored by Git.

To omit the large precomputed ColabFold indices, as in this repository, set:

```bash
MMSEQS_NO_INDEX=1 scripts/truncate_micron_from_sample_hits.sh ...
```

Validate sample-hit coverage with:

```bash
scripts/validate_micron_sample_coverage.sh \
  /path/to/work ./microdbs /path/to/samples.csv 4
```

The reduced databases are test fixtures, not substitutes for full databases in production or scientific analyses.
